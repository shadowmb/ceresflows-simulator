# 🤖 Hydroponics Controller Simulator v5.5

## 📋 Общ преглед
Симулаторът на CeresFlows е мощен инструмент за тестване на автоматизацията без нужда от физически хардуер. Той имитира поведението на контролери (Arduino Uno R4 WiFi), техните сензори и релета.

### 🏗️ Архитектура (Consolidated)
Проектът е обединен в една структура за по-лесна поддръжка:
- 💻 **Frontend**: React 19 + Vite (намира се в `src/`)
- 🧠 **Backend**: Node.js + TypeScript (намира се в `server/`)
- 📂 **Config**: Локални копия на шаблоните за контролери и сензори (намира се в `config/`)
- 📊 **Data**: Динамични данни, профили и пин-асигнации (намира се в `data/`)

---

## 🚀 Режими на работа

### 1. Режим на разработка (Development)
За да виждате промените по кода в реално време, пуснете два терминала:
- **Терминал 1 (Frontend):** `npm run dev` (достъпен на `localhost:5173`)
- **Терминал 2 (Backend):** `npm run server` (достъпен на `localhost:3001`)

### 2. Режим за ползване (Production)
След компилация се използва само една команда:
- `npm run server` — той автоматично зарежда готовия интерфейс от папка `dist/`.

## 📦 Сглобяване и Деплой (Build & Release)

### 📂 Портативна папка (Препоръчително за Windows & RPi5)
Този метод създава папка `release/`, която съдържа всичко необходимо, включително и Node.js за Windows.
```powershell
npm run build:release
```
**Какво съдържа `release/`:**
- `server.cjs` — целият бекенд код в един файл.
- `node.exe` — портативна версия на Node.js (само за Windows).
- `dist/` — компилираният React интерфейс.
- `config/` — шаблоните за устройствата.
- `start-windows.bat` / `start-linux.sh` — стартови скриптове.

### 💾 Един EXE файл (Standalone Windows)
Опитва се да пакетира всичко в едно EXE в `release/bin/`.
```powershell
npm run build:exe
```
*Забележка: Поради актуализацията към Node v24, този метод може да изисква `--no-bytecode` или специфична версия на pkg.*

---

### 🥧 Работа с Raspberry Pi 5
1. Копирайте папка `release/` на RPi 5.
2. Дайте права за изпълнение: `chmod +x start-linux.sh`
3. Стартирайте: `./start-linux.sh` (изисква предварително инсталиран Node.js на Linux).

## 🛠️ Важни аспекти

### 🔄 Синхронизация на шаблоните
Симулаторът използва шаблоните от `simulator/config`. Ако правите промени по основния бекенд на Hydroponics, копирайте актуализациите:
- **От:** `backend/config/`
- **Към:** `simulator/config/`

### 🔌 Протоколи
- **UDP Broadcast**: Симулаторът отговаря на порт `8888` за автоматично откриване.
- **MQTT**: Поддържа връзка към MQTT брокер за отдалечено управление.
- **Scenario Engine**: Позволява изпълнение на автоматизирани сценарии за промяна на сензорните стойности във времето.

### 📍 Пин-асигнации
Симулаторът помни кой сензор на кой пин е закачен за всеки контролер. Тези данни се пазят в `simulator/data/assignments_[CONTROLLER_ID].json`.
